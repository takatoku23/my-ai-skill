# フロントエンド

React、Next.js、TypeScript を軸に、Web 標準、ブラウザ API、パフォーマンス、ビルドツール、テストツール、UI ライブラリなど、フロントエンドエンジニアの技術力を高める情報を扱う。英語圏の一次情報を優先する。

## 収集先

- ニュースレター・公式ブログ（最重要）: JSer.info、This Week in React、bytes.dev、JavaScript Weekly、Frontend Focus、react.dev/blog、nextjs.org/blog、web.dev、Chrome for Developers Blog、WebKit Blog
- OSS 公式: Storybook、TanStack、Vite、GitHub Trending のフロントエンド関連
- 日本語: Zenn（react / typescript / nextjs / frontend / css）、Qiita、はてなブックマーク（30 users 以上）
- その他: Hacker News（50 points 以上）、dev.to、Smashing Magazine

週次のニュースレターは期間内に出た最新号を見る。

## 採用

- React、Next.js、TypeScript の新 API、破壊的変更、RFC、移行ガイド
- Web 標準とブラウザの新機能（CSS、View Transitions、Baseline 入りした API など）
- パフォーマンス改善の実践報告と計測手法
- ビルドツール、テストツール、開発体験の改善（Vite、Biome、Vitest、Turbopack など）
- コンポーネント設計、状態管理、データフェッチのパターン
- UI ライブラリ、デザインシステムの新しいアプローチ
- TypeScript の高度な型の使い方

## 除外

- AI ツール、AI サービスの話題（→ ai）
- キャリア論、組織論（→ engineering）
- 入門、チュートリアル
- 1 年以上前の内容、まとめ転載、PR 記事
